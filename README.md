# STAVO — Official Web Presence

Landing page for STAVO, a sportswear & streetwear brand blending sport and street identity.

## Stack
React · Vite · Tailwind CSS · Framer Motion

## Scenes

- Scene 0 — Animated hero with STAVO title + model image  
- Scene 1 — Brand manifesto with per-word blur-in animation  
- Scene 2 — Scrollable shop with flip-card product cards  

## Navigation
Mouse wheel, trackpad scroll, and mobile swipe all advance between scenes.
