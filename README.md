STAVO — Official Web Presence
Landing page for STAVO, a sportswear & streetwear brand blending sport and street identity.
Stack: React · Vite · Tailwind CSS · Framer Motion
Scenes:

Scene 0 — Animated hero with STAVO title + model image
Scene 1 — Brand manifesto with per-word blur-in animation
Scene 2 — Scrollable shop with flip-card product cards

Navigation: Mouse wheel, trackpad scroll, and mobile swipe all advance between scenes.

A few quick tips for the repo setup:

Set visibility to Private if you don't want the source public yet
Add a Node .gitignore to avoid committing node_modules
Skip the license for now unless you want it open source
