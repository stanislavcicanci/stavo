# STAVO Landing Page

React + Vite landing page for STAVO with three scroll-driven scenes:

- Hero scene with animated logo and cloud motion
- Brand manifesto with word-by-word reveal
- Shop scene with flip-card product grid

## Tech

- React + Vite
- Tailwind CSS
- Framer Motion

## Entry point

`src/Intro.jsx` is wired as the main page entry through `src/main.jsx`.

## Development

```bash
npm install
npm run dev
npm run lint
npm run build
```
